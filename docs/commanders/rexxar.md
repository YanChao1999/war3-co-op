# 雷克萨 — 杜隆塔尔冒险小队

**背景：** 对应《冰封王座》兽人额外关卡「杜隆塔尔的建立」——雷克萨带着同伴游历，而不是开城造兵。

**核心差异：** **无常规军队**，只有 **3 名英雄**。

| 成员 | 单位 |
|------|------|
| 雷克萨 | 兽王（Rexxar） |
| 洛坎 | 暗影猎手（Rokhan） |
| 陈·风暴烈酒 | 熊猫酒仙（Brewmaster） |

| 项 | 内容 |
|----|------|
| 建筑 | 仅牛头人帐篷营地标记（**不产兵**） |
| 经济 | 无苦工；定时补给金木 |
| 资源 | **羁绊**（击杀） |
| 技能 | `-revive` 救回一名倒下的同伴 |
| 终极 | `-beasts` 召米莎与刺毛野猪限时助战 |

选用：`-pick rexxar` / `-pick 雷克萨`
