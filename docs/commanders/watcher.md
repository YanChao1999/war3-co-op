# 守望者（玛维）

**核心差异（不是换皮资源）：** **复仇经济 + 机动猎杀**

| 对比 | 阿尔萨斯 | 守望者 |
|------|----------|--------|
| 资源来源 | 敌军死亡 → 灵魂 / 复活敌军 | **己方阵亡 → 复仇**；敌军死亡几乎不给 |
| 技能 | 花灵魂抬尸 | **闪现改站位**，落点布复仇之灵陷阱 |
| 终极 | 亡灵大军 | **复仇化身**：灵体潮，鼓励之后继续“死人充电” |

## 指令

- `-pick watcher` / `-pick 守望者` / `-pick 玛维`
- `-blink` 向面向方向闪现
- `-avatar` 复仇化身

## 设计意图

越惨烈越强：防守战损反而给油。鼓励敢搏、敢换，而不是无损发育。
