# 伊利丹 — 背叛者

**核心差异（不是换皮资源）：** **献祭经济 + 形态切换**

| 对比 | 常规召唤系（萨尔/泰兰德） | 伊利丹 |
|------|---------------------------|--------|
| 资源来源 | 主要靠击杀慢慢攒 | 击杀很少；**主动杀掉己方战斗单位**换邪能 |
| 技能手感 | 花资源换临时兵 | 花友军换爆发与续航（自疗 + 短时萨特） |
| 终极 | 再召一波 | **英雄变成恶魔形态**，并带末日守卫/地狱火，限时后变回 |

## 指令

- `-pick illidan` / `-pick 伊利丹`
- `-consume` 献祭附近友军（非英雄/工人）
- `-meta` 恶魔变身（需邪能）

## 设计意图

逼玩家做“血债”决策：推线时要不要砍自己人换变身窗。和纯召唤流节奏完全不同。
