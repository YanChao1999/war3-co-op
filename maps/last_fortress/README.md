# Last Fortress terrain map

- `template.w3x` — World Editor input (read-only for Wurst builds)
- Root `LastFortress.w3x` — same starter archive used by `tools/build.sh`

Gameplay entities (fortress, outposts, mines, bases) are **spawned by script** so this blank TFT template is playable. See `tools/WORLD_EDITOR.md` to author real terrain.
